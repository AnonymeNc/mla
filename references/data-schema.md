# Hero data schema

Every hero entry should expose:
- id: stable slug that can be used in URLs
- name: display name
- type: faction-like type such as Hybrid, Elemental, Tech, Martial, Light, Dark, Order, Chaos, Astral
- rarity: UR, SSR, SR, R
- class: role such as Mage, Marksman, Support, Fighter, Tank
- advancedClass: optional specialization such as Warlock, Oracle, Inquisitor, Dragon Knight, Strategist, Spirit, Sniper, Ranger, Arcanist, Iron Guard
- equipmentSize: Light, Medium, Heavy
- description: concise summary for card and detail views
- image: local asset path or remote URL
- wikiUrl: canonical wiki link
- tags: list of search adjectives and category labels
