Fan-made, not official

This is an unofficial, fan-made reference site for Mobile Legends: Adventure. It is not affiliated with, endorsed by, or sponsored by the game's publisher. All game assets, hero names, and artwork belong to their respective owners.

Sources & credits

Hero data is sourced from the community wiki and kept up to date automatically. Guides and FAQ content are compiled from the community Discord's guide channels, with contributions and corrections from players.

Open source & contributions

This site is open source and free to use. Found an error, an outdated hero, or want to suggest a guide? See the Contributing guide on GitHub — anyone can submit a fix.

How this site is built

Built as a plain static site (no framework, no tracking, no ads), hosted for free on GitHub Pages. Source code is available on GitHub.
